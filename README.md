# 📄 pdfjin-ai-chat

> Chat with any PDF document using AI (Gemini, Claude, or OpenAI) by PDFJin by [PDFJin](https://pdfjin.com).

[![PyPI version](https://img.shields.io/pypi/v/pdfjin-ai-chat.svg)](https://pypi.org/project/pdfjin-ai-chat/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)

Fast, private, and local document processing with zero size limits.

> 🌐 **Prefer a Web UI?** Use the free online browser tool at **[https://pdfjin.com/pages/ai-pdf-chat.html](https://pdfjin.com/pages/ai-pdf-chat.html)**.

---

## 📦 Installation

```bash
pip install pdfjin-ai-chat
```

Or install from source:

```bash
git clone https://github.com/pdfjin/pdfjin-ai-chat.git
cd pdfjin-ai-chat
pip install .
```

---

## 🚀 Quickstart

Run via CLI:
```bash
pdfjin-ai-chat --help
```

Use in Python:
```python
import pdfjin_ai_chat
```

---

## 🧪 Testing

```bash
pip install pytest
```
